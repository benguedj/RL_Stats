RL Stats

Privacy policy

Last updated: October 29, 2026

RL Stats is a free, open-source overlay for Rocket League, made by Benjamin Guedj. It has no account, no analytics, no ads, and it doesn't collect, sell or share any personal data. This page explains exactly what it stores and what it connects to. It applies to every version: Microsoft Store, zip download and winget.

What is stored on your PC

Everything RL Stats saves stays on your computer, in %APPDATA%\RL Stats:

  • Settings (overlay style, colors, options) and your current session.
  • Match history: result, mode, score and stats of each online match, with the in-game names and platform IDs of the players in it (used for your teammate stats and the "opponents met before" feature).
  • A log file used to diagnose problems.

None of this is sent anywhere. To delete it, delete that folder. It is kept when you uninstall the app, so you don't lose your history if you reinstall.

RL Stats also enables Rocket League's Stats API in Documents\My Games\Rocket League\TAGame\Config\TAStatsAPI.ini and reads the game's display settings in the same folder.

Network connections

  • Rocket League Stats API: match events are read from a local socket provided by the game (127.0.0.1:49123). Nothing leaves your PC.
  • Update check (zip and winget versions only): at startup, the app asks the GitHub API (api.github.com) for the latest version number. No personal data is sent; GitHub sees your IP address, as with any web request. It can be turned off in the settings. The Microsoft Store version doesn't do this: the Store handles updates.
  • Discord status (off by default): your mode, session score and streak are sent to the Discord app running on your PC, which shows them on your profile.
  • Streamer mode (off by default): a page for OBS served on 127.0.0.1 only, not reachable from other devices.
  • Links (this website, GitHub, player profiles on rocketleague.tracker.network) open in your browser, only when you click them.

This website

This site is hosted by GitHub Pages and uses no cookies or trackers. It loads fonts from Google Fonts and asks the GitHub API for the latest version number. The demo video is loaded from YouTube only when you click play.

Changes and contact

If this policy changes, this page is updated with a new date. Questions: open an issue on GitHub.

Politique de confidentialité

Dernière mise à jour : 29 octobre 2026

RL Stats est un overlay gratuit et open source pour Rocket League, réalisé par Benjamin Guedj. Pas de compte, pas de statistiques d'utilisation, pas de publicité : il ne collecte, ne vend et ne partage aucune donnée personnelle. Cette page détaille ce qu'il enregistre et à quoi il se connecte. Elle s'applique à toutes les versions : Microsoft Store, zip et winget.

Ce qui est enregistré sur ton PC

Tout ce que RL Stats enregistre reste sur ton ordinateur, dans %APPDATA%\RL Stats :

  • Les réglages (style de l'overlay, couleurs, options) et ta session en cours.
  • L'historique des matchs : résultat, mode, score et stats de chaque match en ligne, avec les pseudos et identifiants de plateforme des joueurs présents (pour les stats de coéquipiers et les « adversaires déjà croisés »).
  • Un fichier journal qui sert à diagnostiquer les problèmes.

Rien de tout ça n'est envoyé où que ce soit. Pour l'effacer, supprime ce dossier. Il est conservé quand tu désinstalles l'appli, pour ne pas perdre ton historique si tu la réinstalles.

RL Stats active aussi la Stats API de Rocket League dans Documents\My Games\Rocket League\TAGame\Config\TAStatsAPI.ini et lit les réglages d'affichage du jeu dans le même dossier.

Connexions réseau

  • Stats API de Rocket League : les événements de match sont lus sur un socket local fourni par le jeu (127.0.0.1:49123). Rien ne sort de ton PC.
  • Vérification des mises à jour (versions zip et winget uniquement) : au démarrage, l'appli demande à l'API GitHub (api.github.com) le numéro de la dernière version. Aucune donnée personnelle n'est envoyée ; GitHub voit ton adresse IP, comme pour toute requête web. Désactivable dans les paramètres. La version Microsoft Store ne le fait pas : c'est le Store qui gère les mises à jour.
  • Statut Discord (désactivé par défaut) : ton mode, le score de la session et ta série sont envoyés à l'appli Discord de ton PC, qui les affiche sur ton profil.
  • Mode streamer (désactivé par défaut) : une page pour OBS servie sur 127.0.0.1 uniquement, inaccessible depuis les autres appareils.
  • Liens (ce site, GitHub, profils des joueurs sur rocketleague.tracker.network) : ouverts dans ton navigateur, seulement quand tu cliques dessus.

Ce site

Ce site est hébergé par GitHub Pages et n'utilise ni cookies ni traceurs. Il charge des polices depuis Google Fonts et demande à l'API GitHub le numéro de la dernière version. La vidéo de démo n'est chargée depuis YouTube que quand tu cliques sur lecture.
